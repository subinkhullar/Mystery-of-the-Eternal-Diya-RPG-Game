# 🪔 Mystery of the Eternal Diya 🪔
### by Subin Khullar

An immersive AI-powered Diwali detective adventure that combines treasure hunting, mystery solving, escape room challenges, RPG progression, collectibles, achievements, analytics, and festival-themed storytelling within a modern Progressive Web Application (PWA).

Become the Royal Festival Detective and recover the legendary **Eternal Diya** before darkness consumes the kingdom.

---

# 🌟 Story

On the eve of Diwali, the sacred **Eternal Diya**, a mystical lamp that illuminates the entire kingdom, suddenly disappears.

As darkness begins spreading across Ayodhya and celebrations fade, you are summoned by the Royal Council to investigate.

Search ancient temples, bustling markets, hidden tunnels, sacred shrines, and mysterious palaces to uncover clues, interrogate suspects, recover sacred Flame Fragments, and reveal the true culprit before Diwali Night arrives.

Will you restore the Festival of Lights in time?

# 🚀 Installation

## Option 1: Local Browser

1. Download all project files.
2. Ensure the following files exist:

```text
index.html
styles.css
app.js
service-worker.js
manifest.json
```

3. Open index.html in a modern browser.

---

## Option 2: Local Web Server

Recommended for PWA functionality.

### Using VS Code

1. Install Live Server extension.
2. Open the project folder.
3. Right-click index.html.
4. Select "Open with Live Server".

---

## Option 3: GitHub Pages

1. Create a GitHub repository.
2. Upload all files.
3. Enable GitHub Pages.
4. Access the generated website URL.

---

## Option 4: Netlify

1. Create a Netlify account.
2. Drag and drop project folder.
3. Site deploys instantly.
